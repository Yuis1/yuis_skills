# 双语维护契约

本仓库中的英文和简体中文文档是地位相同的语义镜像。贡献者可以从任一语言开始修改，但必须在同一个变更集中更新配对文档。任何一种语言都不是生成产物、翻译分支或备用事实源。

## 文件布局

- 默认发现文件使用英文：`README.md`、`AGENTS.md` 和 `SKILL.md`。
- 中文镜像在同一目录下追加 `.zh-CN.md`。
- 本地化技能镜像属于参考文档，而不是第二个可发现技能，因此两种语言共用同一个技能身份、安装路径、脚本、资源和参考资料。
- `chatgpt-chat` 是唯一仅使用英文的例外，因为其正常工作流不需要用户编写 Prompt。

## 修改流程

1. 使用贡献者的母语修改任一版本。
2. 合并前更新配对文档。完整保留每项要求、禁令、默认值、例外、示例、命令、链接和范围边界。
3. 运行：

   ```bash
   python3 scripts/checks/check_bilingual_docs.py
   python3 -m unittest tests/test_bilingual_docs.py
   ```

4. 由精通两种语言的 Reviewer 或高水平双语模型进行语义复审。结构检查不能证明翻译质量。
5. 如果不改变规则就无法协调两个版本，应停止修改，将分歧作为原文内容决策处理，而不是静默选择其中一种语言。

## 自动化能够证明什么

检查器能够证明必需的镜像均存在，并且标题层级、列表结构、围栏代码、受保护的行内标识符、URL、相对路径和语言导航保持一致。它有意不使用关键词或机器翻译比较正文，因为这些方法会对语义等价造成虚假的信心。

遗漏、约束强度变化、术语漂移、不自然表述和意外范围变化仍须由语义复审负责。

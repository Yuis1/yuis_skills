# 野心提示词重写

本技能的目标是消除人类请求与模型能力之间的“野心代沟”。受限于人类自身的自我效能感，我们常常把模型局限在浅层的初级事务中。本技能将表面、狭隘的任务草稿，在 `Altitude`、`Depth` 与 `Range` 三个维度重构重写为高杠杆、专业级的执行指令。

适用于任何显得平庸、局限在局部修补或惯性思维中的提示词、任务草稿或特性诉求，在正式动手前释放其最高价值潜力。

## 重写管线

1. **将名词解构为动词：**
   - 剥除表面的交付物形式，例如演示文稿、脚本或数据库表。
   - 提炼核心动作、需要证明的因果链条、所要求的行为改变，以及在不确定性下要做出的关键决策。
2. **升高维度（关注结果与自闭环）：**
   - 探寻初始目标背后的终极目标：追问这之后必须发生什么。
   - 从让模型执行单次手工修补，跃迁为要求模型设计持久运行的自闭环机制，减少人工例行介入。
   - 在提示词中指明模型自主验证所需的外部环境与基础设施，例如环境复现、版本与提交映射以及原始调用链抓取能力。
3. **下潜深度（专业工具与外部裁判）：**
   - **坚持行业顶尖工具：** 拒绝二手摘要或玩具格式（如简单的 Markdown 表格总结）；要求调用顶尖专家使用的一手原始原料、统计学模型、AST 分析引擎或原生性能剖析工具。
   - **把严苛目标变为合理工程：** 设定看似激进的目标（如 200 毫秒延迟、零崩溃保障或完全自动化复现），并明确作为可解的工程约束要求模型攻坚。
   - **对抗性检验认知：** 要求模型直接用原始数据对抗性检验既有业务认知与假设。
   - **强制引入外部裁判：** 严格禁止在同一生成回路中由模型自我评判。在存在机械量化指标时（测试套件、编译器、Profiler），强制接入；在缺乏机械断言的场景下，将评判绑定至独立的外部裁判（如独立自动化脚本、明确的人工验收契约，或在独立、无污染会话中运行的裁决模型）。
4. **拓展广度（按方法论组建团队）：**
   - 将解构出的动词映射到正交领域，例如做空机构、法务会计、动效设计师或调查记者。
   - 强制要求引入其专业分析方法与证据规范，坚决禁止空洞的语气扮演。
5. **合成重写提示词：**
   - 将升维后的要求汇总为一份完整、自洽的重写提示词草案。

## 严格约束

- 重写提升的是问题杠杆，不是无用复杂度。严禁以“野心”为借口索要空洞框架、无用抽象或臃肿架构。
- 每个重写后的提示词都必须包含外部裁判。禁止同一链路内的自我评估，评判必须来自外部工具、显式验收测试或独立的裁决会话。
- 严禁空洞的语气角色扮演。引入跨学科视角时，必须规定具体的方法论、工具与证据，而非对话套话。
- 仅交付升维分析与重写提示词，不强行预设下游衔接流程。

## 交付格式

必须交付：

1. **升维增量分析：**
   - *核心动词：* 替代表面名词的本质动作与决策。
   - *高度跃迁：* 取代单点修补的自闭环流程或终极结果。
   - *深度与外部裁判：* 引入的专家级工具、底层一手原料与外部裁判定义。
   - *广度引入：* 引入的正交领域方法论与对抗性审查。
2. **重写后提示词：**
   - 提供一个干净、可直接复制的代码块，包含完整的高野心重写提示词。
